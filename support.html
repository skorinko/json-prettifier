Support

Turning it on, using it, and what to do when something doesn’t work.

Turn it on: Mac

  1. Open the JSON Prettifier for Safari app once. Its window shows whether the extension is on.
  2. Click Quit and Open Safari Settings…, or in Safari choose Safari › Settings › Extensions.
  3. Tick JSON Prettifier. It needs no access to your websites unless you turn on automatic formatting.

Turn it on: iPhone and iPad

  1. Open Settings, then Apps, then Safari, then Extensions.
  2. Tap JSON Prettifier and turn on Allow Extension.

Then open a JSON address, such as the sample document, and try it.

Use it

  • Format a page: click the JSON Prettifier button in the Safari toolbar, then Format This Page, or press ⌃⇧J. Do it again to see the page as it was. On iPhone and iPad, tap the page menu button beside the address, then JSON Prettifier, then Format This Page.
  • Every JSON page by itself: in the toolbar button, turn on Format JSON pages automatically, and give it access to websites when Safari asks. Untick a site there to leave its pages as they are.
  • Find: type in the search box, or press / or ⌘F. Return goes to the next match. The funnel button shows only the matches. Start with $ for a JSONPath query, such as $..price.
  • Copy: click a value: its path shows at the bottom, with Copy Path and Copy Value. ⌘C copies the value too. The copy button at the top copies the whole document, formatted or minified.
  • Keys: arrows move and fold, Return folds, E and C expand and collapse everything, 1 to 9 open that many levels, T, P and R switch between Tree, Pretty and Raw. Option-click folds a whole branch.
  • A file on your Mac, or JSON on a page: open the Scratchpad from the toolbar button, then paste, drop the file, or choose Open File…. On a Mac you can also select JSON on any page and choose Format Selection as JSON from the context menu.

Common questions

Nothing happens on a page

Safari doesn’t let extensions into its own pages, such as Settings or the Start Page, or into files opened from disk; use the Scratchpad for those. On an ordinary web page, JSON Prettifier says the page isn’t JSON; select the JSON on it and try again.

Safari downloads the file instead of showing it

Some servers send JSON in a way Safari saves rather than shows, and no extension can change that. Open the downloaded file in the Scratchpad.

A number looks different from another viewer

JSON Prettifier shows numbers exactly as sent. Other viewers round numbers with more than about 16 digits, such as 64-bit IDs. A dotted underline marks such a number; hold the pointer over it to see what JavaScript would make of it.

The page says the site stops extensions from reacting to clicks

Some sites, such as raw files on GitHub, send a setting that keeps extensions from receiving clicks. There the document is shown as formatted text. For the full tree, save the page with File › Save As and open the file in the Scratchpad.

The keyboard shortcut does nothing

A website or another extension may use the same keys. Use the toolbar button instead, or change the shortcut in Safari’s settings, under Extensions.

Safari asks to allow downloads from a long random name

The first time you save a file from the Scratchpad, Safari asks whether to allow downloads from it, naming it by a long random string. That string is the extension’s own address on your device; allowing it is safe.
